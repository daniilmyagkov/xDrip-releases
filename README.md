# xDrip — сборки

Готовые APK-файлы приложения. Исходный код — в отдельном приватном репозитории.

Приложение проверяет обновления здесь: **Настройки → Настройки обновления → включить, репозиторий `daniilmyagkov/xDrip-releases`**.

Каждый релиз помечен датой сборки в формате `ГГГГММДД` и содержит `.apk` во вложениях.
