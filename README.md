# xDrip Redesign — обновления

Готовые APK-файлы приложения. Исходный код — в отдельном приватном репозитории.

Приложение (версии от 7 октября 2026 и новее) само проверяет этот репозиторий при открытии и раз в 4 часа и показывает уведомление «Обновить» / «Оставить».

Каждый выпуск помечен временем сборки (`vГГГГ.ММ.ДД-ЧЧ`) и содержит два файла:
- `xDrip-Redesign-….apk` — приложение «xDrip Redesign» для тестеров;
- `xDrip-Master-….apk` — сборка, которая ставится вместо обычного xDrip (только мастер разработчика).
